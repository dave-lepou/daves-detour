JavaScript and its Relationship to HTML and CSS

To understand how a web page works, imagine building a house: HTML (The structure): This is the frame, gib and foundation. It dictates what is on a webpage, like text, buttons, images etc. CSS (The appearance): This is the paint, wallpaper and furnishings. It controls how the structure looks. Its colours, fonts, layout etc. JavaScript (The functionality and property manager): This is the plumbing, electrical works etc. It controls how the page behaves when a user interacts with it. Beyond adding behavior, JS acts as the "property manager", it can step in to repaint a ceiling, knock down wall or build an entirely new section on the fly without needing to rewrite the original "blueprint".

Control Flo and Loops

Control flow is simply the order in which a computer executes code. By using conditions (checking if something is true or false), you can control which paths your code takes or repeat certain steps. Conditionals (if / else): These are decision branches. Think of ordering food: Am I hungry? Yes > Is there food at home? No > Is it past midnight? No > Order Uber Eats! Loops (for): These repeat an action until a specific condition changes. Example: You keep eating a bag of chips while there are still chips left in the bag. Once the bag is empty (condition becomes false), you stop.

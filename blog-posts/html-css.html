The CSS Box Model - Content, Padding, Border and Margin

In this blog, I am going to discuss three main points. First, i'll will explain the CSS Box Model; secondly, i will talk about the differences between padding, border and margin; and thirdly, i will share some questions i had in my study and research and some answers i found!

What is the CSS box-model?

The way i understood this is i had to create a picture analogy. Where a webpage is like a big warehouse that holds different boxes; of different products; and of different sizes. These boxes are the elements of each page - items that make up the webpage i.e images, text, videos etc. Now i think of the CSS box-model as boxes within and around these different boxes and these 'smaller' (or bigger) boxes determine the space between each of the boxes as well as the distance between the neighbouring boxes in the warehouse. Using CSS rules, you can be deliberate and allocate spaces inside and around these different boxes but you have to remember when you are adding more space within and around the different boxes, the overall size of the (let's call it main) box also increases from items original size. There are four 'boxes' or areas in the CSS box-model which are the CONTENT, PADDING, BORDER and MARGIN. These four areas enable you to manipulate the space in and around individual elements.

The CSS Box Model - Content, Padding, Border and Margin

In this blog, I am going to discuss three main points. First, i'll will explain the CSS Box Model; secondly, i will talk about the differences between padding, border and margin; and thirdly, i will share some questions i had in my study and research and some answers i found!

What is the CSS box-model?

The way i understood this is i had to create a picture analogy. Where a webpage is like a big warehouse that holds different boxes; of different products; and of different sizes. These boxes are the elements of each page - items that make up the webpage i.e images, text, videos etc. Now i think of the CSS box-model as boxes within and around these different boxes (elements) and these smaller (or bigger) boxes determine the space between each of the individual boxes (elements) as well as the distance between the neighbouring boxes in the warehouse. Using CSS rules, you can be deliberate and allocate space inside and around these different boxes (elements) but you have to remember when you are adding more space within and around them, the overall size of the "main" box also increases from items original size. There are four 'boxes' or areas in the CSS box-model which are the CONTENT, PADDING, BORDER and MARGIN. These four areas enable you to manipulate the space in and around individual elements.

What is the difference between Margin, Border and Padding?

To understand the different you must first understand each of these key boxes and their "areas of responsibility" Padding: affects the space around the content. Border: creates a border around the padding (within the combined area of padding and content) seperating the space between content/padding and margin. Margin: this is the allocated space between neighbouring elemnts determening how close or how far the next element(s) are. The key difference between each is the allocated space. Padding is the space immediately around the content; border is seperates the space between padding and margin; and margin seperates the space between individual elements.

Questions that came up during my study / reasearch (and answers i found)

How deliberate can you be when assigning values to the box-model? i.e. does it have to be even spacing? can you just allocate space for one side? or different sizes for each side? The answer i found through research was that you can definitely assign different values to these rules and there are different ways you can code them. e.g. with Padding and Margin's you can simply write margin: 0px 5px 10px 15px as an example. Writing this way assigns these different values to different sides of the margin, without having to write out margin-bottom; margin-left; margin;right; margin-top. Instead the code reads the first value (0px) as TOP; second (5px) as RIGHT; third (10px) as BOTTOM; and fourth (15px) as LEFT. Note there are other ways to write this, this is just one way i found interesting. Another note, boarders do not work the same in this sense. You have to allocate spaces directionally by identifying border sides, size, type of border and colour. e.g. border-bottom: (size)10px (type)solid (colour)white

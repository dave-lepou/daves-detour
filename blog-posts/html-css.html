The CSS Box Model - Content, Padding, Border and Margin

In this blog, I am going to discuss three main points. First, I'll explain the CSS Box Model; secondly, I will talk about the differences between padding, border and margin; and thirdly, I will share some questions I had in my study and research and some answers I found!

What is the CSS box-model?

The best way to understand this is through a picture analogy. Imagine a webpage as a big warehouse that holds different boxes of various products and sizes. These boxes are the elements of each page—the items that make up the website, such as text, images, and videos.

Now, think of the CSS Box Model as extra layers of boxes wrapped within and around these main product boxes. These layers determine the space inside the box as well as the distance between neighboring boxes in the warehouse. Using CSS rules, you can be deliberate and allocate space inside and around these elements. However, you must remember that when you add space around the product, the overall size of the main box grows beyond the original item size!

CONTENT: The actual item inside the box i.e. your text, images, videos etc.

PADDING: The space immediately surrounding the content.

BORDER: The outer frame wrapping around the content and padding (separating the space between padding and margin).

MARGIN: The space outside of the border that pushes away neighbouring boxes.

What is the difference between Margin, Border and Padding?

To understand the difference you must first understand each of these key boxes' specific "areas of responsibility"

Padding: affects the space around the content (sharing the same background colour as the element / content)

Border: Acts as the outer frame around the element + padding, separating them from the margin (outer space)

Margin: The allocated space between neighbouring elements which determines how close / far away they sit.

The key difference between the three comes down to location. Padding is the space inside the border; the border is the frame around it; and margin is the space outside the border that keeps other elements at a distance.

Questions that came up during my research (and answers I found)

1. How deliberate can you be when assigning values? Does spacing have to be even on all sides?

Not at all! You can assign custom values to each individual side. One way I learned is using CSS shorthand. Instead of writing four separate rules for top, right, bottom and left, you can write:

margin: 0px 5px 10px 15px;

The ways I learned to remember how the browser reads this are to think of a clock and work clockwise from Top-Right-Bottom-Left; or remember the acronym TRBL (read it as the word "TROUBLE")

2. Do borders work the exact same way as margins and padding?

Not quite. Borders require a bit more detail because you need to specify three properties for the line to display correctly: size, style, colour. For e.g. if you only require a line along the bottom of an element, you would write: border-bottom: 10px solid white;

3. Are borders always rectangular and solid?

No. There are different shapes you can use as borders. For e.g if you required a rounded border you would use the CSS rule: border-radius: 10px;

There are also different styled borders you can use. For e.g there is a dashed border; double border; and a few more. This feature enhances your ability to personalise each element further and style your page as you wish!
